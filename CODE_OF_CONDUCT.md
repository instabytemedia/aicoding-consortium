# Code of Conduct

The AI Coding Consortium adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
for every consortium space: repositories, issue trackers, working-group calls, and events.

Report violations privately via GitHub (instabytemedia) until the consortium domain is live. Reports are handled confidentially by the
Steering Board; members involved in a report recuse themselves.
