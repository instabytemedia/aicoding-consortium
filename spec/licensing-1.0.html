AICC Technical Report 014

AI Licensing Signals 1.0

Machine-readable content permissions: quote, process, train — declared per resource, honored per fetch.

Status of This Document

This is an Editor's Draft. It has no standing and will change. It is published so that origins, engines, and adjacent standards bodies can shape it before it hardens. Comments via the public repository.

Abstract

Whether AI may use web content is today buried in terms-of-service prose no agent reads and no court enjoys. This report defines a three-verb grant vocabulary — quote (reproduce excerpts with citation), process (read, summarise, act on, without retention beyond the task), train (retain for model training) — declarable per AIX entry ("usage": ["quote", "process"]) and per response (AICC-Usage header, RFC 9651 Structured Fields list). It standardizes the expression of permission; what silence means remains jurisdiction-dependent and out of scope.

1. Semantics

Relationship to IETF AIPREF: the IETF aipref working group is standardising a Content-Usage preference field (draft-ietf-aipref-attach) with its own vocabulary. This report uses the distinct field name AICC-Usage to avoid collision; WG-INTEROP tracks AIPREF and will align or profile the vocabularies before this report advances.

Grants are independent (train does not imply quote). Engines MUST honour an explicit AICC-Usage header for the response it accompanies, SHOULD honour AIX-level grants for indexed resources, and MUST treat the verbs as a floor for their own stricter policies, never a licence override in either direction: a grant conveys permission only to the extent of rights the origin actually holds and cannot convey rights it lacks, and a denial cannot revoke statutory exceptions (e.g. quotation rights). The header exists to make the origin's position explicit and machine-actionable.

2. Considerations

  • Legal honesty. This is a signal standard, not a licence: it removes the "we couldn't know" excuse in both directions, which is precisely its value.
  • Mixed content. UGC entries carry the platform's grant; platforms SHOULD reflect their actual terms with contributors, and mislabelling is a conformance violation attributable to the origin.
