AICC Technical Report 011

Provenance & Freshness 1.0

Checkable trust: who published this, when was it last true, and did a human write it.

Status of This Document

This is an Editor's Draft. It has no standing and will change. It is published so that origins, engines, and adjacent standards bodies can shape it before it hardens. Comments via the public repository.

Abstract

The most expensive token is the one spent on stale or fabricated information. This report adds three checkable properties to AIX entries: a source class (human | ai-assisted | ai-generated | syndicated), a verified timestamp (a self-attested freshness signal: "the origin last reviewed this content on date X" — distinct from modified, attributable only when accompanied by sig), and an optional detached signature over the entry's § 3.1 text extraction, binding content to an origin-published key.

1. Fields

Origins adopting this layer add to AIX entries: "source" (required — mislabelling ai-generated as human is a conformance violation, not an opinion), "verified" (optional ISO date), and "sig" (optional: Ed25519 signature over a canonicalized envelope of {url, hash, source, verified, updated, key-id, signed-at} — the provenance claims themselves are signed, not just the text — with the verification key selected by the signed key-id against /.well-known/aicc-keys.json, never by unsigned fields). Engines SHOULD prefer recently-verified, signed, human-source content when sources conflict, and MUST surface source class when quoting ai-generated content to a user.

2. Security Considerations

  • Self-attestation limits. Signatures prove origin, not truth; an unsigned verified date is self-attestation without attribution. Accountability arrives only with sig: signed claims become attributable and datable.
  • Key rotation. The key file carries validity windows; signatures verify against the key valid at updated time.
  • Relation to C2PA. For media assets, engines SHOULD consume C2PA where present; this layer covers the text web C2PA does not reach.
