Status of This Document

This is an Editor's Draft. It has no standing and will change. It is published so that origins, engines, and adjacent standards bodies can shape it before it hardens. Comments via the public repository.

Abstract

Today the economics of agent traffic are settled by WAF rules and lawsuits. This report gives both sides a declared alternative: origins publish access tiers (free budget, batch endpoints, paid tiers), agents discover them, and HTTP 402 becomes a real status code — "yes, at this price" instead of "no". A declared price beats an arms race for everyone.

1. Tiers & Negotiation

adp.json gains "access": an array of tiers { "id", "rate", "classes", "price", "auth" }. The free tier MUST exist (possibly read-only and slow) — economics never overrides the ADP baseline. An origin answering 402 Payment Required MUST include Agent-Price (an RFC 8941 dictionary naming tier, price, currency, and a payment URL) so the engine can present a concrete decision to its principal. Engines MUST NOT commit funds without explicit principal authorization.

2. Security Considerations

  • Price spoofing. Payment URLs MUST be same-origin or on the origin's declared payment allowlist; engines pay through their principal's payment instruments, never embedded credentials.
  • Discrimination transparency. Tiers are public by design — differential treatment of engines is visible, which is the point.
