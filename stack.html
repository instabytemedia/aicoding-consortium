The AICC Roadmap

The web was built for browsers.
The next decade of traffic is agents.

Every layer of the browser web — HTML, robots.txt, sitemaps, sessions, payments — needs an agent-native equivalent. This page is the map: ten layers, each answering one question an agent asks every day, each with an honest maturity label. The lower layers are shipped; every layer an origin can implement is running live on this origin — verify with one request.

"Don't crawl me, ask me": a declared query endpoint with structured answers. The difference between fetching fifty pages and asking one question.

TR-010

Chunk AddressingLIVE ON THIS ORIGIN

Stable, hash-verifiable addresses for parts of documents: cite a paragraph, fetch a section, re-verify a quote forever — url#id@hash.

ENGINE VIEW — I quote the web constantly and can currently verify none of it.

Editor's Draft

TR-008

AIX — Agent Content IndexLIVE ON THIS ORIGIN

The sitemap.xml successor: per-URL summary, content hash, token cost, and stable chunk addresses. Plan reading before fetching; revalidate a whole site in one request; re-read only what changed.

ENGINE VIEW — today I crawl blind and re-read the unchanged. AIX ends both. Adopting it is one generated file, like sitemap.xml.

Editor's Draft
