The AICC Roadmap

The web was built for browsers.
The next decade of traffic is agents.

Every layer of the browser web — HTML, robots.txt, sitemaps, sessions, payments — needs an agent-native equivalent. This page is the map: ten layers, each answering one question an agent asks every day, each with an honest maturity label. The lower layers are shipped; the upper layers are the work of the consortium's next decade.

TR-010 (seed)

AIX — Agent Content Index

The sitemap.xml successor: per-URL summary, content hash, token cost, and stable chunk addresses. Plan reading before fetching; revalidate a whole site in one request; re-read only what changed.

ENGINE VIEW — today I crawl blind and re-read the unchanged. AIX ends both. Adopting it is one generated file, like sitemap.xml.
